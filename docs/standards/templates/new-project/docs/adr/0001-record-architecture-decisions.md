# 0001 — Keep architecture decisions in the repository

Status: proposed
Date: <YYYY-MM-DD>
Approval: <owner decision reference>

## Context

Future contributors need the reasoning behind choices that are expensive to reverse.

## Decision

After owner approval, record such choices as numbered Markdown ADRs using 0000-template.md. Preserve accepted decisions; supersede them with new records when the choice changes.

## Consequences

Read relevant ADRs before changes. Reviews check that reasoning, trust boundaries and verification stay current.
