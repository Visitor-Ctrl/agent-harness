# Contributing

Start a focused topic branch from the protected default branch. Read the approved north star and architecture, then run the documented local checks. Record expensive-to-reverse choices in an ADR. Keep unrelated improvements in separate issues.

Open a PR with behavior, reason, verification evidence and operational impact. Request independent review. Merge only on passing checks for the current head, then deploy the tested artifact through the approved path. Keep credentials and private account details out of patches and review comments.
